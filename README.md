# ![alt text](data/icons/src/64px.svg) Katalog

A native **KDE/Qt (Kirigami) port of a Flatpak store**, borrowing its
design and per-feature behavior from [Bazaar](https://github.com/kolunmi/bazaar).

## Installation
```bash
flatpak install io.github.zachvlat.qutestore.flatpak
```
or (system)
```bash
sudo flatpak install --system io.github.zachvlat.qutestore.flatpak
```

## Building Flatpak

```sh
git clone https://github.com/zachvlat/qutestore
cd qutestore
./setup-flatpak-build.sh
```
